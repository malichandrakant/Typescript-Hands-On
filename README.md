# TypeScript Hello World 🚀

This repository contains a simple **Hello World program written in TypeScript**.
It demonstrates basic TypeScript syntax, compilation using `tsc`, and execution
with Node.js.

## 📌 Purpose
This project is created to showcase my **TypeScript fundamentals**, development
setup, and understanding of the TypeScript → JavaScript workflow.

### 1️⃣ Install TypeScript (if not installed)
```bash

2️⃣ Compile TypeScript to JavaScript

3️⃣ Run the compiled JavaScript
